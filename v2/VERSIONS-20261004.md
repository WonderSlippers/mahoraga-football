## 启动

在PowerShell中进入本仓库的v2目录，执行 `npm run dev:research`。已运行时直接打开5274；端口占用会报错，不杀其他进程。停止此隔离研究实例使用 `npm run stop:research`，它核验自身身份。DEMO5273和旧站5173是独立实例。

当前同一局域网手机入口：[192.168.2.130:5274](http://192.168.2.130:5274/versions)。该地址取自实际监听器，网络变化后以数据运行页显示为准。没有改Windows旧启动任务；电脑重启后仍需启动新实例。
