# 魔虚罗：足球赛事研究与虚拟模拟

魔虚罗是一个本地运行的足球赛事研究网站，包含赛程和公开报价读取、单场研究、模型实验、虚拟模拟账本及复盘界面。本仓库公开的是**源码、数据库结构迁移、测试与必要配置**，不是运行中的网站。

所有模拟均为纸面实验。公开网页展示赔率只是虚拟成交假设，不代表真实账户可成交价格；模型结论不保证收益，也不连接真实投注账户。

## 开发

- Node.js 22.13 或更新版本；安装依赖：`npm ci`。
- 测试：`node --test tests/*.test.mjs`。
- 类型检查：`npx tsc --noEmit`。
- 若要独立运行，请先使用自己的本地 D1 状态和配置，避免连接或覆盖已有账本。`scripts/local-server-launch.mjs` 需显式设置 `MAHORAGA_D1_STATE_DIR`，其构建候选配置只是原本地环境的运行记录，不是开箱即用的部署入口。

## 数据边界

此仓库没有上传历史票据、个人账本、数据库、备份、环境变量、密钥、本机任务配置，也没有原项目的私有交接及用户操作日志。公开仓库从当前源码创建为新快照；原本地 Git 历史未迁入。
